Healthcare Patient Analytics & Pivot Dashboard

An interactive clinical operations dashboard built in Excel using Pivot Tables, Pivot Charts, and dynamic Slicers. This project analyzes 5,000 patient records to provide instant operational insights into treatment costs, bed occupancy (length of stay), and demographic distributions across medical departments.

---

Executive Dashboard Features

*Interactive Slicers: Dynamic multi-parameter filtering by "Month" and "Gender" that instantly update all dashboard metrics.
*Financial Spending Analysis: Tracks total treatment costs broken down by department and visit type (Emergency vs. Routine).
*Demographic Breakdown: Features a 100% stacked column view showing patient age group distributions across departments.
*Operational Occupancy: Analyzes total length of stay across age brackets to help optimize hospital resource allocation.

---

Architecture & Excel Techniques
*Structured Data Model: Separated presentation layers (`Dashboard` tab) from calculation layers (`Pivot tables` tab) for a clean corporate structure.
*Pivot Field Aggregations: Customized summarization types (Sum, Count) for accurate clinical reporting.
*Visualization Design: Applied horizontal bar charts for long department labels, stacked column charts for proportional demographics, and custom chart formatting.
